# Portfolio implementation

This repository serves two public purposes:

1. the professional portfolio;
2. the special GitHub profile README because the repository name matches the GitHub username.

## Positioning

Primary role family: Software Engineer / Full-Stack Product Engineer.

The portfolio is intentionally evidence-first. It prioritizes a small number of systems with architecture, verification, safety and current-status detail instead of presenting every repository equally.

## Current case studies

- Vida 2.0
- Football Intelligence App
- Personal AI System
- La Mediterránea Store

Client delivery remains visible but secondary.

## Local development

Install dependencies with npm install and run npm run dev.

Before considering a material change complete, run npm run lint and npm run build, then review desktop/mobile behavior and prefers-reduced-motion.

## Claims policy

Do not add unsupported exact performance/accessibility/business-impact metrics.

Do not present the current private Football Intelligence App as a finished Production launch.

Do not expose private Vida or Personal AI System data to make a case study look more detailed.

## Deployment cost rule

This repository may be watched by Vercel. Use local checks first and batch coherent changes before any Preview deployment. Do not use Vercel Preview as an iterative diagnostic runner.
